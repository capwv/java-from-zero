# Java من الصفر ☕

منهج **Java** تفاعلي بالعامية المصرية، مفتوح المصدر وشغال بالكامل في المتصفح:
**[capwv.github.io/java-from-zero](https://capwv.github.io/java-from-zero/)**

## المحتوى

- **14 درس متدرج**: من "ليه Java؟" وتنصيب الـ JDK، لحد الوراثة والواجهات والمجموعات والاستثناءات ومشروع console ختامي.
- **42 سؤال كويز** بإجابة فورية، و**28 تمرين** بالحل النموذجي.
- **معمل Java تفاعلي**: مترجم Java مصغّر مكتوب بـ JavaScript خالص (lexer → parser → interpreter) بيشتغل على جهازك من غير أي سيرفر، مع **10 مهام تدريب موجهة** بتتصحح تلقائيًا بمقارنة الناتج.

## الدروس

1. ليه Java؟ وليه نبدأ بيها
2. تنصيب الـ JDK وتجهيز بيئة العمل
3. أول برنامج ليك: Hello World
4. المتغيرات وأنواع البيانات
5. الشروط: if / else / switch
6. الحلقات: for / while / do-while
7. المصفوفات
8. الدوال (Methods)
9. البرمجة كائنية التوجه: الكلاسات والكائنات
10. الوراثة (Inheritance)
11. الواجهات (Interfaces)
12. المجموعات: ArrayList و HashMap
13. معالجة الاستثناءات (Exceptions)
14. المشروع الختامي: نظام حسابات بنكية في الـ console

## ضمان الجودة

- كل مثال وكل ناتج مطبوع في المنهج (**81 ناتج**) اتنفذ فعليًا على **JDK 11 حقيقي** واتطابق حرفيًا، بما فيها نتايج الـ double زي `28.274309999999996`.
- المترجم المصغّر في المعمل اتقارن بـ JDK 11 على **36 برنامج اختبار** (متغيرات، حلقات، كلاسات، وراثة، overloading، مجموعات، استثناءات، المشروع الختامي) وطلع **مطابق 36/36**.
- نواتج مهام التدريب العشرة متاخودة من تنفيذ حقيقي على JDK 11.
